# CROWN & AMBER

ポートフォリオ作品として制作した、架空のティーブランドのECサイトです。

クラシックなティー文化からインスピレーションを受け、時代を超えて愛されるようなデザインを意識し、タイポグラフィや深みのあるカラー、シンプルで使いやすいショッピング体験にこだわって制作しました。

[🇬🇧 English version](./README.md)

## Live Demo

[デモを見る](https://crown-and-amber.vercel.app/)

## 主な機能

- レスポンシブデザイン
- 日本語・英語切り替え
- 商品一覧ページ
- 商品詳細ページ
- 商品ランキング
- ショッピングカート機能
- 商品数の増減
- カートからの商品削除
- カート内の商品数をリアルタイムで表示
- Local Storageを使用したカートデータの保存
- ホバーアニメーションなどのインタラクティブなUI
- PC・スマートフォンに対応したレスポンシブレイアウト
